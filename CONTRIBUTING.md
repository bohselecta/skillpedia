# Contributing

Read AGENTS.md and the acceptance contract. Change canonical src/ first; keep
triggers distinct and stop conditions intact. Reproduce a defect, preserve it
as a regression, fix the cause, build and validate all targets, then run tests.
Inspect the changed instructions as well as code. No synthetic result may be
reported as native model/connector evidence. Native failures belong in evals
with redacted traces in an approved private location.

Do not contribute employer messages, people records, confidential prompts,
API keys, brand assets without rights or paid-provider dependencies. Keep
scope, model permissions and explicit human authority boundaries stable.
No automatic updater or cross-account sync. Use reviewable commits and
explain any contract change. Good work need not be rewritten for style.
