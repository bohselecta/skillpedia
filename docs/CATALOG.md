# Capability catalog

Skillpedia Chat names are `skillpedia-<suffix>`; Code names are `/skillpedia:<suffix>`. Personal counterparts use `hoyt-<suffix>`. Each skill works independently.

| Suffix | Purpose | Personal Hoyt |
|---|---|---|
| `start` | Attention Window — A calm, source-backed next-action window and a small resumable checkpoint; not a second full project plan. | Yes |
| `capture` | Capture & Clarify — A compact organized capture, proposed next actions, unresolved questions and retained parking lot. | Yes |
| `triage` | Communication Triage — An intake receipt, deduplicated candidate work items, a small Attention Window and optional unsent drafts. | Yes |
| `people` | People & Working Agreements — A minimal roster change or source-backed relationship brief, with unresolved identities clearly marked. | Yes |
| `commitments` | Commitments & Follow-through — A commitment ledger delta and bounded waiting-on/follow-up view, with unsent drafts when useful. | Yes |
| `blockers` | Blockers & Escalation — A concise issue/risk record and actionable escalation draft with source evidence and unresolved questions. | Corporate only |
| `decisions` | Decision Briefs & Log — A decision card or append-only decision history update with explicit proposed/decided state. | Yes |
| `meetings` | Meeting Loop — A focused agenda or evidence-backed recap, decision/action delta and optional unsent follow-up. | Yes |
| `updates` | Status & Handover — A concise update or handover, source-to-claim trail and exact asks. | Yes |
| `reply` | Clear Replies — One ready-to-review draft with a clear CTA where appropriate and a brief note about unresolved facts. | Yes |
| `plan` | Plan & Rebalance — A bounded delivery or personal work plan with dependencies, acceptance and explicit trade-offs. | Yes |
| `research` | Evidence-led Research — A supported research brief with checked sources, access dates, limitations and the next decision or experiment. | Yes |
| `spec` | Requirements & Acceptance — A concise implementable contract and acceptance map, with unresolved material decisions clearly bounded. | Corporate only |
| `design` | Architecture & Experience — An implementable architecture/experience blueprint with trade-offs, state coverage and visual requirements. | Corporate only |
| `project` | Contract-to-Delivery Project — Working in-scope deliverables, current contract/status, acceptance evidence and verified delivery within authorization. | Yes |
| `debug` | Evidence-driven Debugging — An evidence-backed diagnosis and verified repair, or a precisely bounded hypothesis with the next check. | Corporate only |
| `review` | Independent-minded Review — Prioritized findings or an evidence-bounded no-findings result, coverage limits and a precise repair handoff. | Yes |
| `masterwork` | Masterwork — The actual revised deliverable or justified no-change result, plus a minimal evidence-based handoff. | Yes |
| `foundry` | Skill Foundry — Complete usable skill packages, reproducible build/validation, eval cases and exact installation steps. | Yes |
| `bridge` | Reviewed Environment Bridge — A minimal reviewed method packet and import prompt, or a blocked transfer with a safe blank template. | Yes |
