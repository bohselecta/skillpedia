# Acceptance contract — frozen 1.0.0

The requested product is the skills and their installation packages, not an
Expedia deployment. Report each evidence class separately.

| ID | Required result | Evidence |
|---|---|---|
| A01 | 20 distinct corporate capabilities; 16 matching personal capabilities | Canonical catalog, generated manifest, tests |
| A02 | Each chat ZIP has one top-level folder, one root SKILL.md and local references | Archive validator; isolated extraction/helper checks |
| A03 | Native Code plugin/marketplace layout, namespaced commands, no hidden hooks or connector grants | Manifest checks; official-format source record; native CLI still required |
| A04 | Partial coverage, proposed ownership, unresolved deadlines, critical exceptions and overflow survive | Instructions plus executable normalized-fixture tests |
| A05 | People are source-backed, minimally scoped and collision-safe | Roster schema/helper tests; native language extraction still required |
| A06 | Local updates are versioned, explicit, idempotent and no-clobber | Patch, replay, conflict, filesystem and CLI tests |
| A07 | Personal/corporate bridge defaults closed and binds exact reviewed payload | Allowlist/hash/release/tamper/export tests; human declassification not automated |
| A08 | Contract freeze, evidence, review/masterwork distinction and bounded escalation retained | Canonical steps, static guards and pilot rubric |
| A09 | Clear installation, first-use, failure recovery, provenance and MIT/Expedia permission | README, guides, LICENSE and packaging tests |
| A10 | Reproducible source-to-native-to-archive build, checksums and CI | Determinism and clean-copy rebuild; CI result tied to commit |
| A11 | Original documentation imagery readable at wide/narrow sizes | Inspected local browser renders; not a live work-system UI |
| A12 | Source delivered to requested GitHub repository without unrelated changes | Commit readback and reviewable branch/PR |
| H01 | ChatGPT account scan, discovery and real reference reads | NOT_RUN until receiving-account evidence |
| H02 | Claude Chat scan, enabled discovery and real reference reads | NOT_RUN until approved-workspace evidence |
| H03 | Claude Code official validation, discovery and optional reviewer invocation | NOT_RUN until installed CLI/host evidence |
| H04 | Raw-language triage, tool behavior and repeated use on approved sources | NOT_RUN; offline record tests are not native model evals |
| H05 | Corporate approval, participant usefulness and real operating outcomes | NOT_RUN; no company data or users were studied |

Do not weaken H gates into PASS because syntax tests succeed. The release is an
implemented, locally verified package for receiving-host evaluation, not a
certified integration or claim of organizational adoption.
